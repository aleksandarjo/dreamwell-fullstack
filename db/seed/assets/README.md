# Seed property images

Shared development photos for seeded properties. Each file path relative to this folder is its object path in the `property-images` Supabase Storage bucket (for example `seed/house/suburban-house-exterior.webp`). These objects are shared by many seeded properties: deleting a property must never delete them.

All files are WebP, resized to a maximum width of 1600 px with the original aspect ratio preserved. They were downloaded from Wikimedia Commons, where each file page records its license.

Upload missing files with `npm run storage:upload-seed-images` (requires `SUPABASE_SECRET_KEY` in `.env.local`). Existing objects are skipped, never overwritten or deleted.
